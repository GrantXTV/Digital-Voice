<h1>Digital Voice HF encoder / decoder, based on the NBTV sound transmission system </h1>

This Project is a place holder for the the HF digital voice system that is designed to work within the same bandwidth as SSB, using to modes:
XDX15 and XDX27. That uses OFDM 12 digital voice carriers with 3 pilot carriers and 24 digital voice carriers with 3 pilot carriers using any SDR modulator with I & Q inputs and outputs from a sound device.  Naming: 
X for experimental.
DX for longdistance.
15 or 27 number of RF carriers used.
