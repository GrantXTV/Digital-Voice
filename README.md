<h1>Digital Voice HF encoder / decoder, based on the NBTV sound transmission system </h1>

This Project is a place holder, for the the HF digital voice system, that is designed to work within the same bandwidth as SSB, using two new modes:
XDX15 and XDX27. That uses OFDM with 12 digital voice carriers with 3 pilot carriers and 24 digital voice carriers with 3 pilot carriers using any SDR modulator / demodulator with I & Q inputs and outputs from a stereo sound device. The naming: 
X for experimental.
DX for longdistance.
15 or 27 number of RF carriers used.  

Update will be posted at future date on this software.
